# 楽々牌譜エディター（ASP.NET Core / Blazor 版）

`牌譜ビューア_卓表示_分岐機能あり.html` を ASP.NET Core（.NET 8、Blazor Web App・Interactive Server）で作り直したものです。
天鳳6形式（tenhou.net/6 の JSON）の牌譜を読み込み、卓表示・巡目移動・自動再生・分岐検討ができます。
牌譜の展開・和了判定・分岐処理はすべてサーバー側の C# で行い、卓は SVG で描画します。

## 起動

.NET 8 SDK が必要です。

```bat
dotnet run
```

ブラウザで http://localhost:5080 を開きます（Visual Studio で `PaifuViewer.csproj` を開いて実行することもできます）。

## 画面

- 左：局一覧・局情報・巡目選択（配牌／鳴き／リーチ／和了へのジャンプ）・再生
- 中央：卓（ブラウザの大きさに合わせて拡大。4 人の手牌・副露・河、中央にドラ・供託・残り枚数・各家の点数）
- 上部の「牌山」：その局の牌山を卓の上に重ねて表示（下記）
- 右：分岐・状態・ログ・局の結果
- 幅の狭い画面では卓を上に、各欄をその下に縦並びで表示
- 起動直後は空の卓と各欄だけを表示し、牌譜を読み込むと反映します
- 閲覧中は卓（緑の部分）をクリックすると牌譜どおりに 1 手進みます

## 分岐（卓上で直接操作）

「この局面から分岐開始」を押すと、牌譜と別の展開を卓の上で操作できます。

- 打牌：手番の家の手牌をクリック（マウスを乗せると牌が持ち上がります）。卓（緑の部分）をクリックするとツモ切り
- 操作ボタン（ツモ・ロン・ポン・カン・チー・暗槓／加槓・リーチ・スルー）は、誰の操作でも視点の家の手牌の右上にまとめて出ます。
  ボタンには視点から見た家（自家・下家・対面・上家）が付きます
- チー・ポンは、鳴きに使う手牌をクリックしても選べます。1 枚で鳴き方が決まればそのまま鳴き、
  候補が複数あれば（例：4m に対して 2356m の 3m）もう 1 枚を選びます
- スルーは、ボタンのほか卓のダブルクリック・右クリックでも選べます
- 打牌に対してロン・鳴きのできる家がなければ、スルーを押さずに自動で次のツモへ進みます
- 分岐中は上部のチェックが「手番の視点に移動する」に変わり、オンにすると手番の家の視点へ自動で切り替わります
- 巡目選択（◀ ▶・スライダー・ジャンプ）や再生の ◀ ▶| は分岐中の局面列の中で移動します。
  戻った局面から別の操作をすると、その先は牌山どおりに進み直します
- 合法な操作だけが選べます
  - ロン・ツモは役がある場合のみ。フリテン（自分の河に当たり牌がある／当たり牌を見逃した同巡内・リーチ後）ならロンは出ません
  - 鳴いた直後の喰い替え（鳴いた牌・チーの筋の牌）は切れません。リーチ宣言中はテンパイを保てる牌だけが選べます
  - 槓は 4 回まで、海底牌（残り 0 枚）では鳴けません
- 和了すると役・符・飜・点数を計算し、本場・供託を含めて各家の点数に反映します（結果は右の「局の結果」）。
  荒牌平局ではノーテン罰符を精算します
- ツモは牌山どおり。牌山データ（下記）があれば牌譜に出てこない先のツモも実際の牌山から引きます。
  牌山データがなく牌譜のツモが尽きた場合は、卓上に出る未使用牌の一覧から選択

キー操作：← → で 1 手移動、Space で再生／停止。JSON は「牌譜を読み込む」またはドラッグ＆ドロップで読み込めます。

## シミュレーション（和了率・放銃率・流局率）

右の「シミュレーション」欄に、表示中の局面から局の終わりまでを何度も打った結果を表示します。
牌譜の閲覧中・分岐中のどちらでも、局面を移動するたびに背景で計算し直します（計算済みの局面は覚えておきます）。

- 視点の家から見えない牌（他家の手牌・牌山・裏ドラ）を毎回ランダムに並べ替え、4 人ともボットで打ちます
  - 打牌：向聴数が最も小さくなる牌、同じなら受け入れ枚数の多い牌。鳴いた手は役（タンヤオ・染め手）に合わない牌から切る
  - 鳴き：役牌のポン（後付けを含む）、タンヤオ・染め手の鳴き（鳴いて向聴数が進み、3 向聴以内になるとき）
  - リーチ：門前でテンパイしたらリーチ。ダマで 5,200 点以上ならダマ。他家のリーチに待ちが少ないときは追いかけない
  - 押し引き：リーチや 3 副露（2 副露の終盤）の他家がいれば、テンパイは打点・待ち・危険度、1 向聴は打点の見込みと残り枚数で押すか決め、
    それ以外はベタオリ（現物 → 筋・壁・字牌 → 無筋。副露がタンヤオ・染め手なら合わない牌を安全寄りに読む）
  - しきい値は `Core/Simulator.cs` の `BotParams` にまとめています
- 結果は視点の家から見て「自家和了・放銃・他家ツモ・横移動・流局」に分け、平均収支も出します
- 視点の家の打牌番（または鳴き・ロンを選べる場面）では、選べる操作（打牌・立直打牌・ツモ和了・スルー・ポン・チー・ロン）ごとに
  同じ回数ずつ打ち、平均収支の高い順に並べます。牌譜で実際に選んだ打牌には「（牌譜）」が付きます
- 「局面ごとの推移」は計算済みの手の和了率・放銃率・流局率を折れ線で表示します。「全手の推移」で局のすべての手をまとめて計算します（1 手 100 回まで）
- 数値はボットの打ち方で決まる目安です。同じ条件での操作どうしの比較に使ってください

### ボットの成績（自動対戦）

ボットどうしで東場の 1 局を配牌から打たせて成績を測れます（3 つ目以降の引数で `BotParams` の値を変えて試せます）。

```bat
dotnet run -- --selfplay 8000
dotnet run -- --selfplay 4000 PushHan1=2.5 DamaValue=7700
```

既定の値での 8,000 局の結果（1 人あたり）は、和了率 21.3%・放銃率 12.8%・副露率 31.3%・立直率 18.8%・流局率 15.5%、平均打点は約 5,100 点です。
雀魂の上位卓（雀聖〜魂天）の平均（和了率 22〜23%・放銃率 10〜11%・副露率 30〜35%・立直率 18〜20% 程度）に寄せていますが、
和了率と放銃率の差は上位の打ち手より小さく、打点も低めです（手役を狙った手作りや、相手の手の細かい読みはしません）。
- 試行回数は 100／300／1000 回から選べます。牌山データがあっても、シミュレーションでは見えない牌を並べ替えて使います

## 牌山データ（雀魂）

`tools/majsoul-paipu.user.js`（Tampermonkey 用）は、雀魂の牌譜を開いて `s` キーを押すと天鳳6形式の JSON を保存します。
天鳳6形式に加えて、各局の牌山（雀魂の `RecordNewRound.paishan`）を拡張キー `"paishan"` として出力します。

```json
{ "log": [ ...局ごとのデータ... ], "paishan": [ [136 枚の牌コード], ... ] }
```

- `paishan[i]` は `log[i]` の局の牌山（牌コードは `log` と同じ。赤5 は 51/52/53）
- 天鳳の牌譜ビューアや NAGA は知らないキーを無視するため、従来どおり使えます
- ビューアは牌譜の実際のツモ順が牌山のどこに並んでいるかを照合してから使います。照合できない場合は使わず、
  局情報欄に「牌山データが牌譜のツモと一致しないため未使用」と表示します
- 嶺上牌の位置は牌譜の嶺上ツモと照合して決めます。その局でカンがなかった場合は王牌の末尾からと推定します
- 「牌山」ボタンで、配牌・ツモ山・王牌（嶺上牌の位置つき）を表示します。ツモ済みの牌は薄く、次のツモ牌は枠で示します。
  牌山データがない場合は、牌譜からわかるツモ順だけを表示します

## 点数計算

- 一般形・七対子・国士無双に対応し、手牌の分け方と待ちの取り方のうち最も高い点数を採用します
- 喰いタンあり・赤ドラあり・数え役満あり。切り上げ満貫・包（責任払い）・槍槓・人和・流し満貫は扱いません
- 国士無双十三面・四暗刻単騎・純正九蓮宝燈・大四喜はダブル役満
- 裏ドラは牌譜に記録がある場合（そのリーチ和了が牌譜にある局）のみ数えます。記録がなければ結果にその旨を表示します

## ファイル構成

| ファイル | 内容（元 HTML の対応箇所） |
|---|---|
| `Program.cs` | ASP.NET Core の起動設定 |
| `Components/App.razor`, `Routes.razor` | HTML の骨組みとルーティング |
| `Components/Pages/Viewer.razor` | 画面全体・卓の SVG 描画・操作（`render` など） |
| `Core/ViewerState.cs` | 表示状態・移動・分岐の合法手と適用（`go` / `bp` / `disc` / `call` / `kan` など）、フリテン判定 |
| `Core/Scoring.cs` | 和了の役・符・飜・点数計算 |
| `Core/RoundBuilder.cs` | 牌譜 1 局を 1 手ごとの局面に展開（`build`） |
| `Core/Simulator.cs` | シミュレーション（見えない牌の並べ替え・ボット・集計） |
| `Core/Shanten.cs` | 向聴数の計算 |
| `Core/SelfPlay.cs` | ボットどうしの自動対戦と成績の集計 |
| `Core/Tiles.cs` | 牌コード変換・和了／テンパイ判定（`norm` / `tn` / `agari` / `tenpai`） |
| `Core/Model.cs` | 局面・プレイヤー・河・副露のデータ型 |
| `Core/Json.cs` | JSON パーサ |
| `wwwroot/app.css`, `app.js` | 見た目（ライト／ダーク対応）、キー操作・ドラッグ＆ドロップ |
| `wwwroot/tiles/` | 牌画像（麻雀王国） |

## 牌画像

牌画像は [麻雀王国「麻雀素材」](https://mj-king.net/sozai/) の牌画2（47×63 ピクセル）を使用しています。
配布元の条件：自由に使用可・連絡不要・改造/再配布可・著作権は放棄しない（出典表示を推奨）。
赤5 の画像は配布されていないため、5 の画像を赤く着色した PNG（`p_*5r_*.png`）を同梱しています。
