# 牌譜ビューア（C# / Windows Forms 版）

`牌譜ビューア_卓表示_分岐機能あり.html`（HTML / CSS / JavaScript）を C# に移植したデスクトップアプリです。
天鳳6形式（tenhou.net/6 の JSON）の牌譜を読み込み、卓表示・巡目移動・自動再生・分岐検討ができます。

## 画面

- 左：局一覧・局情報・巡目選択（配牌／鳴き／リーチ／和了へのジャンプ）・再生
- 中央：卓（ウィンドウに合わせて拡大。4 人の手牌・副露・河、中央にドラ・供託・残り枚数・各家の点数）
- 右：分岐・状態・ログ・局の結果

## 分岐（卓上で直接操作）

「この局面から分岐開始」を押すと、牌譜と別の展開を卓の上で操作できます。

- 打牌：手番の家の手牌をクリック（マウスを乗せると牌が持ち上がります）
- ツモ和了・暗槓／加槓・リーチ：手番の家の手牌の上に出るボタン
  （リーチ宣言中はテンパイを保てる牌だけが選べ、選べない牌は薄く表示されます）
- ロン・ポン・カン・チー：打牌に対して鳴ける家の手牌の上に出るボタン。鳴かない場合は卓中央の「スルー」
- ツモは牌譜の牌山どおり。牌山が尽きたら、卓上に出る未使用牌の一覧から選択

キー操作：← → で 1 手移動、Space で再生／停止。JSON はドラッグ＆ドロップや起動引数 `PaifuViewer.exe 牌譜.json` でも読み込めます。

## ビルド

### .NET SDK なし（Windows 標準のコンパイラ）

```bat
build.bat
```

`bin\PaifuViewer.exe` ができます（C# 5 の範囲で書いてあるため .NET Framework 4.x の `csc.exe` でビルドできます）。
牌画像は `tiles` フォルダから読み込みます。exe を別の場所に移す場合は `tiles` フォルダを exe と同じ場所にコピーしてください。

### .NET 8 SDK がある場合

```bat
dotnet run
```

## 牌画像

牌画像は [麻雀王国「麻雀素材」](https://mj-king.net/sozai/) の牌画2（47×63 ピクセル）を使用しています。
配布元の条件：自由に使用可・連絡不要・改造/再配布可・著作権は放棄しない（出典表示を推奨）。
赤5 の画像は配布されていないため、5 の牌画像を赤く着色して表示しています。
`tiles` フォルダが見つからない場合は、文字で描いた牌で表示します。

## ファイル構成

| ファイル | 内容（元 HTML の対応箇所） |
|---|---|
| `src/Program.cs` | エントリポイント |
| `src/MainForm.cs` | 画面構成・卓の描画・クリック操作・分岐（`render` / `bp` / `disc` / `call` / `kan` など） |
| `src/RoundBuilder.cs` | 牌譜 1 局を 1 手ごとの局面に展開（`build`） |
| `src/Tiles.cs` | 牌コード変換・和了／テンパイ判定（`norm` / `tn` / `agari` / `tenpai`） |
| `src/Model.cs` | 局面・プレイヤー・河・副露のデータ型 |
| `src/Theme.cs` | 配色・フォント・牌画像の読み込みと描画 |
| `src/Json.cs` | 依存なしの JSON パーサ |
| `src/SampleData.cs` | 起動時に表示するサンプル牌譜 |
| `tiles/` | 牌画像（麻雀王国） |

## 注意

ビルドしたばかりの署名なし exe は、Windows Defender が誤検知してブロックすることがあります。
その場合は Windows セキュリティの「保護の履歴」から、自分でビルドしたファイルであることを確認したうえで許可してください。
