# 牌譜ビューア（C# / Windows Forms 版）

`牌譜ビューア_卓表示_分岐機能あり.html`（HTML / CSS / JavaScript）を C# に移植したデスクトップアプリです。
天鳳6形式（tenhou.net/6 の JSON）の牌譜を読み込み、卓表示・巡目移動・自動再生・分岐検討ができます。

## 機能

- 局一覧・局情報・巡目選択（スライダー、◀ ▶ で 1 巡移動、配牌／鳴き／リーチ／和了へのジャンプ）
- 卓表示（河・副露・他家の手牌、視点切り替え、ツモ切りは灰色・鳴かれた牌は半透明・立直宣言牌は枠表示）
- 手牌表示（自分のみ／全員）
- 分岐：任意の局面から打牌・チー・ポン・カン・リーチ・ツモ／ロンを選んで別展開を確認
  （ツモは牌譜の牌山どおり。牌山が尽きたら未使用牌から選択）
- 再生（0.5× ～ 4.0×）、ログ、局の結果
- キー操作：← → で 1 手移動、Space で再生／停止
- JSON はドラッグ＆ドロップ、または起動引数 `PaifuViewer.exe 牌譜.json` でも読み込めます

## ビルド

### .NET SDK なし（Windows 標準のコンパイラ）

```bat
build.bat
```

`bin\PaifuViewer.exe` ができます。コードは C# 5 の範囲で書いてあるため、Windows に標準で入っている
.NET Framework 4.x の `csc.exe` でそのままビルドできます。

### .NET 8 SDK がある場合

```bat
dotnet run
```

## ファイル構成

| ファイル | 内容（元 HTML の対応箇所） |
|---|---|
| `src/Program.cs` | エントリポイント |
| `src/MainForm.cs` | 画面構成・描画・操作・分岐（`render` / `bp` / `disc` / `call` / `kan` など） |
| `src/RoundBuilder.cs` | 牌譜 1 局を 1 手ごとの局面に展開（`build`） |
| `src/Tiles.cs` | 牌コード変換・和了／テンパイ判定（`norm` / `tn` / `agari` / `tenpai`） |
| `src/Model.cs` | 局面・プレイヤー・河・副露のデータ型 |
| `src/Theme.cs` | 配色・フォント・牌の描画（CSS の `.t` など） |
| `src/Json.cs` | 依存なしの JSON パーサ |
| `src/SampleData.cs` | 起動時に表示するサンプル牌譜 |

## 注意

ビルドしたばかりの署名なし exe は、Windows Defender が誤検知してブロックすることがあります。
その場合は Windows セキュリティの「保護の履歴」から、自分でビルドしたファイルであることを確認したうえで許可してください。
